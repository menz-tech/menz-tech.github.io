# موقع Menz Tech

موقع ثنائي اللغة (عربي / English) يشتغل على GitHub Pages مجاناً، بدون سيرفر وبدون قاعدة بيانات.
كل النصوص بملف واحد `content.json`، والصور بمجلد `assets/uploads`، وتعدّلها من لوحة التحكم `/admin/`.

## 1) الرفع على GitHub (مرة وحدة)

1. سوّي ريبو جديد باسم `اسم_حسابك.github.io` (Public).
2. فك ضغط الملف، وافتح الريبو واضغط **Add file ← Upload files**.
3. اسحب **كل** المحتويات (index.html, style.css, app.js, content.json, مجلد admin, مجلد assets, وباقي الملفات) واضغط **Commit changes**.
   - اسحب المحتويات نفسها، مو المجلد الأب.
   - لازم يكون `index.html` بجذر الريبو مباشرة.
4. **Settings ← Pages**: Source = **Deploy from a branch**، Branch = **main**، Folder = **/(root)**، واضغط Save.
5. بعد دقيقة أو دقيقتين الموقع يشتغل على `https://اسم_حسابك.github.io`.

## 2) لوحة التحكم

الرابط: `https://اسم_حسابك.github.io/admin/`

أول مرة تحتاج توكن (Token)، تسويه مرة وحدة:

1. افتح https://github.com/settings/personal-access-tokens/new
2. Token name: أي اسم. Expiration: سنة.
3. Repository access ← **Only select repositories** ← اختار ريبو الموقع.
4. Permissions ← Repository permissions ← **Contents** ← **Read and write**.
5. Generate token، انسخه والصقه بلوحة التحكم.

من اللوحة تكدر:
- تعدّل أي نص بالعربي والإنكليزي.
- تغيّر الصور (الواجهة، الشعار، المعرض، شعارات العملاء). الصور تنضغط تلقائياً قبل الرفع.
- تضيف وتحذف وترتّب الخدمات والأسئلة والخطوات.
- تحط رقم واتساب (من تبويب **إعدادات عامة**). **هذا أهم حقل**: كل طلبات الزبائن تروح لهذا الرقم.

بعد ما تضغط **حفظ ونشر** التعديلات تظهر بالموقع خلال دقيقة تقريباً.

## 3) أقسام تظهر وتختفي لوحدها

- **المعرض** و**العملاء**: ما يظهرون بالموقع إلا إذا ضفت لهم صور أو جهات.
- رقم الاتصال والبريد والدوام: يظهرون إذا كتبتهم، وإذا تركتهم فارغين يختفون.

## 4) دومين خاص لاحقاً (اختياري)

إذا اشتريت دومين، حطه بـ **Settings ← Pages ← Custom domain**، وسوّي سجلات DNS حسب تعليمات GitHub. الموقع ما يحتاج أي تغيير.

## ملاحظات

- ما تفتح `index.html` بالضغط المزدوج على جهازك، لأن المتصفح يمنع قراءة `content.json` من ملف محلي. للتجربة المحلية شغّل `python -m http.server` داخل المجلد وافتح `http://localhost:8000`.
- لوحة التحكم مفتوحة كرابط، بس ما تشتغل بدون التوكن. لا تشارك التوكن مع أحد.
- النسخة الاحتياطية: زر **نسخة احتياطية** باللوحة ينزّل `content.json`.
