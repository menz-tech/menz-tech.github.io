لوحة تحكم الموقع

من هنا تعدّل النصوص والصور، والموقع يتحدث لوحده بعد الحفظ.

شلون أسوي التوكن؟ (مرة وحدة بس)
  1. افتح github.com/settings/personal-access-tokens/new.
  2. Token name: اكتب أي اسم مثل menz-admin. وخلّي Expiration سنة.
  3. Repository access: اختار Only select repositories وبعدها اختار ريبو الموقع بس.
  4. Permissions ← Repository permissions ← Contents ← اختار Read and write.
  5. اضغط Generate token، وانسخ التوكن والصقه فوق.

التوكن ينحفظ بمتصفحك بس، وما ينرسل لأي جهة غير GitHub. إذا تستخدم جهاز مو إلك، شيل علامة "تذكرني".
